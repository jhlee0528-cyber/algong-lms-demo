# 알공 LMS 공부방용 개선 프로젝트

## 프로젝트 정보
- **프로젝트명**: 알공스마트리 LMS (공부방용)
- **목표**: 소규모 공부방/학원 환경에 최적화된 LMS 개선
- **핵심 작업**: 신규미션 생성 시 과제 선택 옵션 2개 → 4개 확장

## 기술 스택
- **Frontend**: React 18+ with TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Query (TanStack Query) + Zustand
- **Backend**: Node.js + Express (또는 Next.js API Routes)
- **Database**: MySQL 또는 PostgreSQL
- **Build Tool**: Vite

## 코딩 컨벤션

### 파일/폴더 명명
- 컴포넌트: PascalCase (예: `TaskSelector.tsx`)
- 훅: camelCase with 'use' prefix (예: `useLibraryBooks.ts`)
- 유틸리티: camelCase (예: `formatDate.ts`)
